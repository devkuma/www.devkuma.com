mkdirコマンド

ディレクトリを作成する。mkdirはmake directoryの略である。

使用方法

mkdir [作成するディレクトリ名]

オプション

  • -p: 親ディレクトリも作成する。

使用例

ルートディレクトリにtestディレクトリを作成する。

mkdir /test

この操作にはroot権限が必要である。

現在のディレクトリでaの中にbを作成する。

mkdir a/b

aが存在しない場合は作成されない。aとbをまとめて作成するには-pを使う。

mkdir -p a/b
