Java のインストールと開発環境の作成

Tags:
  • Java

Java でアプリケーションを開発するには、一般的に JDK と開発ツールソフトウェアをインストールする。

JDK(Java Development Kit)

JDK は、Java アプリケーションを実行するための Java 仮想マシンをはじめ、コンパイラやデバッガなどのツールを備えた Java 開発環境である。Oracle のサイトからダウンロードできる。
コード自体は一般的なテキストエディタで作成できるため、JDK だけがインストールされていれば最小限のアプリケーション開発は可能である。

Java インストール - 実行およびコンパイル環境の作成

  • OpenJDK のダウンロードとインストール
    • https://jdk.java.net/
  • Java SE Development Kit(JDK) のダウンロードとインストール
    • http://java.sun.com/javase/downloads/index.jsp
  • OS 環境変数の設定
    • JAVA_HOME={JDK インストールパス}
    • PATH={JAVA_HOME}\bin

OS ごとにインストール方法が異なるため、それぞれの環境に合った設定が必要である。

統合開発環境

統合開発環境(Integrated Development Environment, IDE)は、コーディングを支援するコードエディタをはじめ、デバッガ、プロジェクト管理機能、リファクタリング機能など、アプリ開発にはおおむね欠かせないさまざまな機能を備えたソフトウェアである。最小限のコーディングであれば、確かにテキストエディタだけでも可能である。しかし、コンパイル、配置、デバッグなど開発時に繰り返し発生する作業は面倒であり非生産的でもある。本格的な開発では統合開発環境の利用が一般的であり、実務でも当然求められる。早めに統合開発環境での開発に慣れるとよい。

代表的な Java の統合開発環境には IntelliJ IDEA、Eclipse などがある。以前は Eclipse が多く使われていたが、最近は JetBrains の IntelliJ IDEA がよく使われている。
