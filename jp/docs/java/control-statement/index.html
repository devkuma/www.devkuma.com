Tags:

Javaの制御文は、大きく条件文、繰り返し文、分岐文の3種類に分けられます。

条件文

  • if ~ else文
  • switch ~ case文

繰り返し文

  • for文
  • for ~ each文
  • while文
  • do ~ while文

分岐文

  • break文
  • continue文
  • return文
