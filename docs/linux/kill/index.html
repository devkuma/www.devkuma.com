kill 명령어

프로세스 종료시킨다.

사용법

kill (option) [PID:프로세스 아이디]

option(signal):

  • -1 : 재실행(HUP)
  • -9 : 강제종료(KILL)
  • -15 : 기다렸다 정상 종료(TERM)

kill 명령어 사용 예제

// 프로세스명이 tomcat인 항목의 PID 확인
$ ps -ef | grep tomcat
  501  2177     1   0 11:36PM ttys000    0:05.94 

... 생략 ...

// PID가 2177인 프로세스 종료
$ kill -9 2177
