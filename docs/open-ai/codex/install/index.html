OpenAI의 Codex 설치 및 사용 방법

Codex는 OpenAPI에서 개발한 “AI 기반 소프트웨어 엔지니어링 에이전트"이다.
Tags:
  • AI
  • Codex

개발자 입장에서 중요한 점은 Codex는 “설치형 프로그램”이라기보다 여러 방식으로 연결해서 사용하는 도구다.

즉, 로컬에 무조건 설치해야 하는 구조가 아니라 ChatGPT, CLI, IDE, 웹 같은 다양한 방식으로 사용할 수 있다.

Codex 설치

ChatGPT에서 사용 (가장 쉬운 방법)

사실 대부분은 별도 설치 없이 시작한다.

방법

  1. ChatGPT 로그인
  2. Codex 기능 활성화 (플랜 필요)
  3. 바로 사용

Codex는 ChatGPT 플랜에 포함되어 제공된다.

특징

  • 설치 없음
  • 바로 사용 가능
  • 가장 간단한 방식

Mac 환경에서 CLI 설치 (개발자 추천)

Mac 환경의 터미널 기반으로 Codex를 쓰고 싶다면 이게 핵심이다.

사전 준비

먼저 기본 환경부터 체크해야 한다.

아래 사항은 필수이다.

  • macOS (Ventura 이상 권장)
  • Node.js (18 이상)
  • npm 또는 pnpm
Node 설치 (안 되어 있다면)
brew install node

설치 확인:

node -v
npm -v

Codex CLI 설치

공식적으로 제공되는 CLI 설치 방식이다.

npm install -g @openai/codex

설치 확인:

codex --version

로그인 (가장 중요)

codex

처음 실행하면, 다음과 같이 콘솔 화면이 표시된다.

  Welcome to Codex, OpenAI's command-line coding agent

  Sign in with ChatGPT to use Codex as part of your paid plan
  or connect an API key for usage-based billing

> 1. Sign in with ChatGPT
     Usage included with Plus, Pro, Business, and Enterprise plans

  2. Sign in with Device Code
     Sign in from another device with a one-time code

  3. Provide your own API key
     Pay for what you use

  Press Enter to continue

여기서 1번 ChatGPT 계정으로 로그인 선택하면, 브라우저가 열린다.

로그인을 하게 되면 CLI와 계정이 연결된다.

이 다음으로 콘솔에 표시 되는 내용을 확인하고, 버튼을 몇번 누르면 드디어 사용할 준비가 끝났다.

사용 흐름

다시 정리하자면, 사용 흐름을 아래와 같다.

  • CLI에서 codex 실행
  • 로그인 진행 (ChatGPT 계정)
  • 프로젝트 폴더에서 실행
  • 자연어로 작업 지시

이 과정이 끝나면 CLI와 계정이 연결된다.

예:

"이 프로젝트에 Redis 캐싱 추가해줘"

IDE 확장 (VS Code 등)

사용 방법

  1. VS Code 열기
  2. Codex 확장 설치
  3. 로그인

장점

  • 코드 보면서 바로 수정
  • 자동 리팩토링
  • 코드 리뷰 지원

웹 / 앱 기반 사용

Codex는 아래 방식도 지원한다:

  • Codex 웹
  • Codex 전용 앱
  • GitHub 연동

특히 웹에서는 GitHub 연결이 필요함

Codex 사용

API / SDK 방식 (고급)

백엔드에서 직접 쓰고 싶다면:

  • OpenAI API 키 사용
  • Codex 모델 호출
  • 자동화 시스템 구축

개발자 기준의 추천 설치 사용

현실적으로 이렇게 나뉜다:

  • 입문
    • ChatGPT → 바로 사용
  • 실무
    • CLI + IDE 같이 사용
  • 고급
    • API + 자동화 (CI/CD 연동)

정리

중요한 포인트 (많이 헷갈림)

“Codex 설치 = 프로그램 다운” 이게 아니다. 정확히는 “Codex를 사용할 수 있는 인터페이스를 설치하는 것”

개발자 팁

이렇게 쓰면 효율 좋다.

  • CLI: 큰 작업 (리팩토링, 기능 추가)
  • ChatGPT: 아이디어 / 설계
  • IDE: 세밀한 수정

조합해서 쓰는 게 핵심이다.

한 줄 요약

Codex는 설치하는 도구가 아니라, 연결해서 쓰는 AI 개발 에이전트다
