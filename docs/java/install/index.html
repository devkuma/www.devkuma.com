Java로 어플리케이션을 개발하려면 일반적으로 JDK, 개발 도구 소프트웨어를 설치한다.

JDK(Java Develpment Kit)

JDK는 Java 어플리케이션을 실행하기 위한 Java 가상 머신을 비롯해, 컴파일러나 디버거 등의 툴을 갖춘 Java 개발 환경이다. 오라클 사이트에서 다운로드할 수 있다.
코드 자체는 일반 텍스트 편집기으로 작성할 수 있으므로, JDK만 설치되어 있으면 최소한의 어플리케이션 개발이 가능하다.

자바 설치 - 실행 및 컴파일 환경 만들기

  • OpenJDK 다운로드 및 설치
    • https://jdk.java.net/
  • Java SE Development Kit(JDK) 다운로드 및 설치
    • http://java.sun.com/javase/downloads/index.jsp
  • OS 환경 변수 설정
    • JAVA_HOME={JDK 설치 경로}
    • PATH={JAVA_HOME}\bin

각 OS별 설치 방법이 다르기 때문에, 각 환경에 맞는 설정 필요하다.

통합 개발 환경

통합 개발 환경(Integrated Development Environment, IDE)은 코딩을 지원하는 코드 에디터를 비롯하여 디버거, 프로젝트 관리 기능, 리팩토링 기능 등 앱 개발에는 대략 빠뜨릴 수 없는 여러 기능을 갖춘 흔히 갖춘 소프트웨어이다. 최소한의 코딩이라면 확실히 텍스트 편집기만으로도 가능하다. 그러나 컴파일/배치(배포)/디버그 등 개발 시 반복적으로 발생하는 작업은 번거롭기도 하면 비생산적이다. 본격적인 개발에서는 통합 개발 환경의 이용이 일반적이며, 실무에서도 당연히 요구된다. 빠르게 통합 개발 환경에서의 개발에 익숙해지는 것이 좋다.

대표적인 Java의 통합 개발 환경에는 IntelliJ IDEA, Eclipse 등이 있는데, 예전에는 Eclipse를 많이 사용하였지만 최근에는 JetBrain의 IntelliJ IDEA를 많이 사용되고 있다.
