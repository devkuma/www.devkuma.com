Hugo에서 사용하지 않는 템플릿이나 Shotcode 조회 (hugo --printUnusedTemplates)

Hugo에서 사용하지 않는 템플릿이나 Shotcode 조회하는 방법에 대해서 설명한다.
Tags:
  • Hugo
  • Blog

Hugo 사이트를 빌드할 때 사용하지 않는 템플릿을 검색하려면 ,다음과 같이 --printUnusedTemplates 옵션을 사용한다.

% hugo --printUnusedTemplates
Start building sites …
hugo v0.111.3+extended darwin/arm64 BuildDate=unknown

...생략...

WARN 2023/05/14 15:25:46 Template _default/list.rss.xml is unused, source file /Users/user/...생략.../mysite/layouts/_default/list.rss.xml
WARN 2023/05/14 15:25:46 Template _default/single.html is unused, source file /Users/user/...생략.../mysite/themes/docsy/layouts/_default/single.html
WARN 2023/05/14 15:25:46 Template blog/baseof.html is unused, source file /Users/user/...생략.../mysite/docsy/layouts/blog/baseof.html

...생략...

WARN 2023/05/14 15:25:46 Template swagger/single.html is unused, source file /Users/user/user/...생략.../mysite/themes/mytheme/layouts/swagger/single.html
Total in 3146 ms

위의 예에서는 여러개의 템플릿이나 짧은 코드가 사용되지 않는다는 것을 알 수 있다.
